# Blockwild

An original, offline voxel survival sandbox for Android phones and tablets (and any modern
browser). Explore a procedurally generated block world, mine and gather, craft tools, build,
farm, fight creatures, explore caves and ruins, and keep your worlds saved on the device.

Everything you see and hear (block textures, creature models, item icons, UI icons, sounds
and music) is generated by the game's own code at startup. There are no ads, accounts,
analytics or network requests.

- **Android APK (debug build):** [`dist/Blockwild-debug.apk`](dist/Blockwild-debug.apk)
- **Engine:** JavaScript + [three.js](https://threejs.org) (WebGL), bundled with Vite, hosted in
  a minimal native Android WebView app. See [TECHNICAL_DECISIONS.md](TECHNICAL_DECISIONS.md).

## Features

| Area | What is in the game |
|---|---|
| World | Seeded, deterministic infinite-feeling terrain (border at ±16,000 blocks), 16×128×16 chunks streamed around the player, 12 overworld biomes (plains, forest, dense forest, desert, snowy plains, taiga, mountains, beach, swamp, rocky badlands, lakes/seas, blossom grove), rivers, plateaus, caves (tunnels, chambers, flooded/lava depths), ores by depth, trees that cross chunk borders, structures (abandoned shelters, ruined towers, campsites, desert shrines, dungeons with spawner totems, crystal geodes) with loot chests |
| Blocks | 108 blocks: natural, 5 wood types, building blocks, slabs, stairs, fences, doors, hatches, ladders, glass panes, torches, lanterns, ores, functional blocks (workbench, furnace, chest, bedroll), crops, flowers, decorative blocks |
| Rendering | Face-culled chunk meshes with smooth lighting and ambient occlusion, flood-fill sky and block light (torches light caves), HDR bloom + color grading + light shafts + MSAA (Visual effects setting), animated sky (stars, aurora, shooting stars, clouds, sunset, realm skies), reflective water with glitter, torch flicker, biome fog, a 2,300-particle effects system (flames, embers, fireflies, butterflies, petals, splashes, explosions), lightning storms, contact shadows, held item, rain and snow |
| Survival | Health, hunger, saturation and exhaustion, natural regeneration, starvation (difficulty-dependent), fall/lava/cactus/drowning damage, armor, death with item drops, respawn at world spawn or your bedroll, sleeping skips the night |
| Items | 155 items: 30 tools across 6 tiers with real durability and mining speeds, 16 armor pieces, 12 foods, materials, buckets; 85 crafting recipes (hand + workbench), 15 furnace smelting recipes with fuel, transactional crafting |
| Creatures | 4 passive animals (Grazer, Snout, Cluck, Woolly) that wander, flee and follow food; 4 hostiles (Shambler, Skitter, Bonecaster, Gloomling) with an explicit AI state machine, A\* pathfinding, melee/leaps/ranged shots, daylight burning, cave-only spawning, spawn caps by difficulty |
| Modes | Survival and Creative (flight, instant breaking, unlimited blocks, creative catalog, time & weather tools); Peaceful/Easy/Normal/Hard change real gameplay values |
| Farming | Hoe → tilled soil (hydrates near water), wheat seeds and carrots, growth via random ticks, bone meal, harvest |
| Saving | IndexedDB, atomic transactions, autosave every 45 s and on pause/background/quit, versioned format with migration, block palette remapping, validation and repair, damaged-save reporting, world list with thumbnails, rename/copy/delete |
| Controls | Touch: floating joystick, look area, jump/mine/use/sneak/sprint/fly buttons, tap/long-press/double-tap inventory; desktop: WASD, mouse look (pointer lock), mouse buttons, number keys, wheel |
| UI | Main menu over a live voxel landscape, world list, world creation (seed, mode, difficulty, starter kit, advanced rules), settings (graphics, controls, audio, interface/accessibility), pause, death, loading, contextual tutorial, debug overlay (F3) |
| Audio | Procedural WebAudio: material-specific mining/placing/footsteps, creature voices, UI sounds, wind/rain/cave/underwater ambience, sparse generative music; separate volume sliders |

## Playing

**Touch (default on phones):** left side = joystick (walk), drag anywhere else = look.
Right-hand buttons: ⤒ jump, ⛏ mine/attack (hold), ▣ place/use (tap; hold to eat), » sprint,
⌄ sneak (won't fall off edges). Top right: inventory ▦ and pause ‖. Creative adds fly and
fly-down buttons.

**Keyboard/mouse:** WASD move · mouse look (click the game to capture) · Space jump (double-tap
to fly in Creative) · Shift sneak · Ctrl/R sprint · Left click mine/attack · Right click
use/place · E inventory · Q drop · 1–9 / wheel hotbar · F fly (Creative) · F3 debug · Esc pause.

**Inventory:** tap = pick up/put down a stack, long-press (or right-click) = split / place one,
double-tap = quick move. Drop throws the held stack into the world (Creative: Trash).

**Getting started:** break a tree for logs → craft planks → a Workbench → a wooden pickaxe →
mine stone for stone tools → build a shelter and place torches before night.

## Running it

Requirements: Node.js 20+ (tested with 22).

```bash
npm install          # three.js, vite, playwright (test only)
npm run dev          # development server on http://localhost:5173 (also on your LAN with --host)
npm run build        # production build into build/web
npm run preview      # serve the production build on http://localhost:4173
```

The game uses ES modules and Web Workers, so it must be served over HTTP; opening
`index.html` from the file system will not work. Any static file server pointed at
`build/web` works.

## Android

```bash
# Once: Android SDK with platform 35 + build-tools 35 (ANDROID_HOME or android/local.properties)
npm run android:build   # web build -> android/app/src/main/assets/www -> Gradle -> dist/Blockwild-debug.apk
adb install -r dist/Blockwild-debug.apk
```

The app is a single Java activity (`android/app/src/main/java/com/pao2011/blockwild/MainActivity.java`)
with no third-party libraries. It serves the bundled files on the virtual origin
`https://appassets.androidplatform.net/assets/www/`, blocks all network loads, runs
full-screen landscape, keeps the screen on, forwards the back button and app pause to the
game (which pauses and saves), and exposes `vibrate`/`exit` to the page. The only permission
is `VIBRATE`.

A release build must be signed with your own key (none is committed):
`cd android && ./gradlew assembleRelease`, then sign with `apksigner`.

## Project layout

```
index.html              page shell (canvas + UI overlay)
src/main.js             entry point
src/config/             world dimensions and all balance values
src/world/              blocks, tiles, coords, chunk, generator, biomes, structures, lighting,
                        mesher, shapes, raycast, streamer (+ genWorker), world rules (fluids, ticks)
src/entities/           player controller, physics, creature definitions/AI, pathfinding, manager
src/items/              item registry, inventory, recipes & smelting, loot tables
src/game/               app state machine, game session, survival, interaction, settings, tutorial
src/rendering/          three.js renderer, shaders, procedural textures, icons, creature models
src/ui/                 DOM UI: HUD, inventory screens, menus, styles
src/input/              touch + keyboard/mouse input
src/audio/              procedural sound and music
src/save/               serialization (pure) and IndexedDB storage
tests/unit/             Node unit tests
tests/e2e/              Playwright end-to-end runner (+ dev screenshot tools)
scripts/                icon generation, atlas preview, Android sync/copy helpers
android/                Gradle project for the Android WebView host
dist/                   built APK
```

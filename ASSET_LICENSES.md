# Asset and dependency licenses

## Game assets

All game assets are original and generated by code in this repository at runtime or by the
scripts in `scripts/`:

| Asset | Source |
|---|---|
| Block textures (108 tiles, 16×16) | `src/rendering/textures.js` (procedural pixel painters) |
| Item and block icons | `src/rendering/icons.js` (isometric renders of the atlas + pixel templates) |
| HUD icons (hearts, food, armor, air) | `src/ui/hudIcons.js` |
| UI icons | `src/ui/svg.js` (hand-written SVG paths) |
| Creature models | `src/entities/mobs.js` + `src/rendering/mobModels.js` (box models) |
| Sounds, ambience, music | `src/audio/audio.js` (WebAudio synthesis) |
| App/launcher icons | `scripts/make-icons.js` (software rasterizer over the generated atlas) |

No third-party textures, sounds, fonts or branding are included. The UI uses the device's
system font.
